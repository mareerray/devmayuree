project WC2026-tracker

Live World Cup dashboard

A World Cup 2026 dashboard with live score updates, built with React, TypeScript and Vite. Match data powered by the football-data.org API.

Features

  • Group leaderboard — top team in each of the 12 groups
  • Live match tracker with real-time score updates
  • Upcoming matches with date, time and timezone (EEST)
  • Top scorers rankings for WC 2026
  • Latest match results at a glance
  • Tournament progress bar (matches played vs remaining)
  • Image carousel of WC 2026 venues
  • Full group tables for all 12 groups
  • Team search for all 48 teams

Tech Stack

  • React 18
  • TypeScript
  • Vite
  • React Router v6
  • football-data.org API
  • Vitest
  • Vercel
